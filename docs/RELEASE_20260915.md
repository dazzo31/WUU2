## What's New

### 🐛 Critical Bug Fix: WMI Timeout Hang
**Problem**: GUI would hang at "Validating connectivity and services..." for 90+ seconds when testing WMI connectivity on online systems. This was a regression from earlier releases.

**Root Cause**: The `Get-RemoteCredentials` function performed WMI tests using default CIM timeout (90+ seconds) without any timeout protection.

**Solution**: Wrapped all WMI connectivity tests in background jobs with 5-second timeout, matching the proven pattern used in the monitoring phase.

**Impact**: 
- ✅ Connectivity validation now completes in ≤5 seconds (was 90+ seconds)
- ✅ No more GUI hangs during AD import or manual computer list validation
- ✅ Graceful timeout with clear error messages instead of silent hanging

## Technical Changes

### Modified: `WUU.ps1` (Get-RemoteCredentials function, lines 602-670)

#### Before:
```powershell
# Test custom credentials with a simple WMI query
$testResult = Get-CimInstance -ClassName Win32_ComputerSystem -ComputerName $ComputerName -Credential $script:CustomCredentials -ErrorAction Stop
```

#### After:
```powershell
# Test custom credentials with a simple WMI query (with 5s timeout to prevent hangs)
$wmiJob = Start-Job -ScriptBlock {
    param($ComputerName, $Cred)
    try {
        $result = Get-CimInstance -ClassName Win32_ComputerSystem -ComputerName $ComputerName -Credential $Cred -ErrorAction Stop
        return @{ Success = $true; Result = $result }
    } catch {
        return @{ Success = $false; Error = $_.Exception.Message }
    }
} -ArgumentList $ComputerName, $script:CustomCredentials

$jobCompleted = Wait-Job -Job $wmiJob -Timeout 5
if ($jobCompleted) {
    $wmiResult = Receive-Job -Job $wmiJob
    Remove-Job -Job $wmiJob -Force -ErrorAction SilentlyContinue
    if ($wmiResult.Success) {
        # Credentials successful
        return $script:CustomCredentials
    }
}
```

**Changes**:
- WMI tests now run in background job with 5-second timeout
- Returns structured result (`@{ Success = bool; Result/Error = ... }`)
- Proper job cleanup with `Remove-Job`
- Applies to both custom credentials and default credentials testing
